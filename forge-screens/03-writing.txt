------------------------------------------------------------ /tech-blog-article -

  .--[Topic]-- What is the article about? -------------------------------------.
  |  ___ e.g. "Why your Postgres connection pool keeps exhausting"             |
  '----------------------------------------------------------------------------'
  .--[Audience level]-- reader technical level --------------------------------.
  |  ( ) beginner   ( ) intermediate   ( ) advanced                            |
  '----------------------------------------------------------------------------'
  .--[Angle]-- framing --------------------------------------------------------.
  |  ( ) tutorial   ( ) opinion   ( ) deep-dive   ( ) lessons-learned          |
  '----------------------------------------------------------------------------'
  .--[Primary language]-- language/framework for code examples ----------------.
  |  ___ e.g. Python/FastAPI, TypeScript/React, Go, Rust                       |
  '----------------------------------------------------------------------------'
  .--[Word count]-- target length ---------------------------------------------.
  |  ( ) 800   ( ) 1500   ( ) 2500   ( ) Other (custom int 300-5000)           |
  '----------------------------------------------------------------------------'

  '----------------------------------------------------------------------------'
  .--[Format]-- optional  (default: deep dive) --------------------------------.

  '----------------------------------------------------------------------------'
  .--[Constraints]-- optional  (time / length / tools to use or avoid) --------.
  |  ___ empty allowed                                                         |
  '----------------------------------------------------------------------------'
  .--[Distribution]-- optional  (default: technical blog/docs) ----------------.
  |  ( ) blog   ( ) docs   ( ) course platform   ( ) internal wiki   [Other]   |

------------------------------------------------------------------ /github-bio -
  6 free-text fields, asked one per message as plain questions (no menus).
  Answers passed as an argument are kept; only missing questions are asked.

  .--[Role]-- Q1 current role or title ----------------------------------------.
  |  ___ e.g. Senior Full Stack Developer                                      |
  '----------------------------------------------------------------------------'
  .--[Stack]-- Q2 core languages and frameworks -------------------------------.
  |  ___ e.g. Node.js, Express, PHP, Tailwind                                  |
  '----------------------------------------------------------------------------'
  .--[Data]-- Q3 databases and data tools -------------------------------------.
  |  ___ e.g. MySQL, Postgres, Redis   (skip ok)                               |
  '----------------------------------------------------------------------------'
  .--[Cloud]-- Q4 cloud, auth, and hosting ------------------------------------.
  |  ___ e.g. Vercel, Supabase, Clerk   (skip ok)                              |
  '----------------------------------------------------------------------------'
  .--[DevOps]-- Q5 DevOps and system admin ------------------------------------.
  |  ___ e.g. Linux SysAdmin, Git   (skip ok)                                  |
  '----------------------------------------------------------------------------'
  .--[Focus]-- Q6 main focus or specialty -------------------------------------.
  |  ___ e.g. Complex API Architectures   (skip ok)                            |
  '----------------------------------------------------------------------------'
  .--[Confirm]-- summary of all 6, then wait ----------------------------------.
  |  Reply yes to continue, or say what to change.                             |
  '----------------------------------------------------------------------------'
  .--[Result]-- 5 bios, each checked by count_chars.py ------------------------.
  |  Categorized . modern & traditional . keyword dense . concise &            |
  |  professional . visual/vertical.  Each <= 160 chars, shown with count.     |
  '----------------------------------------------------------------------------'


---------------------------------------------------------------- /book-summary -
  Up to 4 questions in ONE plain message (numbered list, no menus).
  Answers passed as an argument are kept; only missing questions are asked.
  Reply "defaults" to accept every default.

  .--[Book]-- Q1 title and author  (required) ---------------------------------.
  |  ___ e.g. Sapiens by Yuval Noah Harari                                     |
  '----------------------------------------------------------------------------'
  .--[Language]-- Q2 optional  (default: English) -----------------------------.
  |  ___ e.g. Spanish                                                          |
  '----------------------------------------------------------------------------'
  .--[Spoilers]-- Q3 optional  (default: allowed) -----------------------------.
  |  ( ) allowed   ( ) avoid ending and major twists                           |
  '----------------------------------------------------------------------------'
  .--[Social post]-- Q4 optional  (default: none) -----------------------------.
  |  ( ) none   ( ) LinkedIn post   ( ) Twitter/X thread                       |
  '----------------------------------------------------------------------------'
  .--[Book check]-- only if the book is unclear, then wait --------------------.
  |  Wrong author -> "Did you mean <book>?"  Unknown -> ask for the            |
  |  publication year, the ISBN, or a short description.                       |
  '----------------------------------------------------------------------------'
  .--[Result]-- one summary, headings in the chosen language ------------------.
  |  Overall Summary . Main Ideas . Key Quotes . Practical Takeaways           |
  |  . Social Post (only if chosen).  Quotes exact or "Paraphrase:".           |
  '----------------------------------------------------------------------------'


----------------------------------------------------------------- /claudepuppy -
  Up to 2 questions in ONE plain message (fixed reply texts, no menus).
  A draft, file path, flavor, or category passed as an argument is kept;
  only what is missing is asked.

  .--[Draft]-- the blog post  (required, about 50+ words of prose) ------------.
  |  ___ paste it, or a path, e.g. drafts/long-threads.md                      |
  '----------------------------------------------------------------------------'
  .--[Flavor]-- dog flavor  (asked if not given) ------------------------------.
  |  ( ) light   ( ) medium   ( ) strong                                       |
  '----------------------------------------------------------------------------'
  .--[Category]-- optional  (default: suggested) ------------------------------.
  |  ( ) Training   ( ) Prompts   ( ) Guides   ( ) Kennel notes                |
  '----------------------------------------------------------------------------'
  .--[Result]-- one rewritten post, facts and code kept exact -----------------.
  |  Title . Summary . Category . Tags . Reading time . post body              |
  |  . What changed (last bullet: "Added sentences:").                         |
  '----------------------------------------------------------------------------'
