  Strip AI voice, strip Unicode, strip comments, clean README feature lists.

  STEP 2 - pick a tool

  .------------------------------------------------------------------------------.
  | [Tool]                                                     Which tool?       |
  |------------------------------------------------------------------------------|
  |  ( 1 )  Strip AI voice                                           -> /unslop  |
  |         Remove AI-generated tone from comments, strings, and names without   |
  |         changing behavior.                                                   |
  |                                                                              |
  |  ( 2 )  Strip Unicode                                     -> /strip-unicode  |
  |         Transliterate messy Unicode down to plain 7-bit ASCII.               |
  |                                                                              |
  |  ( 3 )  Clean README feature list                           -> /strip-emoji  |
  |         Strip leading emoji from feature bullets, label dashes to colons, en |
  |         and em dashes removed.                                               |
  |                                                                              |
  |  ( 4 )  Strip comments                                   -> /strip-comments  |
  |         Delete every comment except file headers, pragmas, and license       |
  |         notices. Preview and approval required.                              |
  |                                                                              |
  |  [Other] type a tool name ................................................   |
  '------------------------------------------------------------------------------'

  STEP 3 - run it
    read commands/<command>.md -> load lib/<tool>/SKILL.md -> "Running /<cmd>."


================================================================================
  STEP 4 - AFTER YOU PICK: the tool's own intake questions
================================================================================
  KEY   ( ) single-pick    [ ] multi-pick    ___ free-text    [Other] escape

----------------------------------------------------------------- /unslop -----
  Question only when the arg is empty/ambiguous; a path or pasted code skips it.

  .--[Target]-- What do you want to unslop? -----------------------------------.
  |  ( ) File   ( ) Directory   ( ) Paste                                      |
  |      (follow-up path/paste request is a plain prompt, not a menu)          |
  '----------------------------------------------------------------------------'


-------------------------------------------------------------- /strip-unicode --
  Question only when the arg is empty/ambiguous; multi-line text runs Paste.

  .--[Target]-- What do you want to clean? ------------------------------------.
  |  ( ) File   ( ) Paste                                                      |
  |      (follow-up path/paste request is a plain prompt, not a menu)          |
  '----------------------------------------------------------------------------'


--------------------------------------------------------------- /strip-emoji ---
  Input question only when the arg is empty; a path or pasted Markdown skips it.

  .--[Input]-- which README?  (one plain line, no menu) -----------------------.
  |  ___ "Which README should I clean? Send a file path, or paste the file     |
  |      contents."   Never guesses a path, never invents a sample             |
  '----------------------------------------------------------------------------'
  .--[Output]-- where the cleaned file goes  (path input only) ----------------.
  |  ( ) Print it (default)   ( ) Overwrite the file                           |
  |      skipped entirely for a paste - a paste is always printed              |
  '----------------------------------------------------------------------------'


------------------------------------------------------------ /strip-comments ---
  Up to 5 fields; DOCSTRINGS and MARKUP asked only when those files turn up.
  A safety gate runs before enumeration: branch, clean tree, version control.

  .--[Scope]-- what should be processed? --------------------------------------.
  |  ( ) Current directory, recursively   ( ) One subdirectory (give path)     |
  |  ( ) Changed files only (git diff)   ( ) A single file                     |
  '----------------------------------------------------------------------------'
  .--[Languages]-- which file types -------------------------------------------.
  |  ( ) Everything found   ( ) One language only (say which)                  |
  |  ( ) Source files, skip templates                                          |
  '----------------------------------------------------------------------------'
  .--[Batching]-- how to work through it --------------------------------------.
  |  ( ) By directory (recommended over ~50 files)   ( ) By language           |
  |  ( ) All at once - small codebase                                          |
  '----------------------------------------------------------------------------'
  .--[Docstrings]-- Python only  (asked only if .py files are found) ----------.
  |  ( ) Keep docstrings (default)   ( ) Remove docstrings too                 |
  |      a docstring is an executable string expression, not a comment         |
  '----------------------------------------------------------------------------'
  .--[Markup]-- template files only  (asked only if they are found) -----------.
  |  ( ) Leave markup comments alone (default)                                 |
  |  ( ) Strip HTML/Blade/Jinja/Handlebars comments too                        |
  '----------------------------------------------------------------------------'
  THEN: enumerate -> file list -> DIFF PREVIEW -> approval -> apply -> verify.
  Nothing is written to disk before the preview is approved.
