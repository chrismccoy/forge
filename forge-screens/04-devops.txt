  |  ___ e.g. "squash my last 3 commits" / "push rejected"                     |
  '----------------------------------------------------------------------------'
  .--[Commits]-- asked once, before the first repository change ---------------.
  |  ( ) Commit for me   ( ) Stage only   ( ) Guidance only                    |

  '----------------------------------------------------------------------------'
  .--[Result]-- the work done, or the exact commands to run -------------------.
