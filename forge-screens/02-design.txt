================================================================================
  STEP 4 - AFTER YOU PICK: the tool's own intake questions
================================================================================
  KEY   ( ) single-pick    [ ] multi-pick    ___ free-text    [Other] escape


-------------------------------------------------------- /html-design-styles -
  Style picker only when the style is unnamed/ambiguous; context gate always.

  .--[Style]-- Which design style?  (skipped if arg names a known style) ------.
  |  ( ) one of 53 catalog styles (display name + one-line desc)               |
  |  ___ examples: bento, brutalist, vaporwave, kawaii, glassmorphism          |
  |      (a category word like "dark"/"modern" opens a sub-picker)             |
  '----------------------------------------------------------------------------'
  .--[Project context]-- Initialization Gate (always) -------------------------.
  |  ( ) full page   ( ) component                                             |
  |  ___ what's being built + any existing markup to restyle                   |
  '----------------------------------------------------------------------------'


------------------------------------------------------- /accessibility-audit -
  Call 1 batches MODE/SCOPE/STANDARD; call 2 is conditional on MODE.

  .--[Mode]-- What to actually do? --------------------------------------------.
  |  ( ) Report   - audit + prioritized report, no edits                       |
  |  ( ) Fix      - audit, edit, verify against baseline                       |
  |  ( ) Component- refactor one pasted component, return code                 |
  |  ( ) Guide    - no audit; apply rules to UI being written now              |
  '----------------------------------------------------------------------------'
  .--[Scope]-- What to audit?  (arg pre-fills first option) -------------------.
  |  ( ) a directory   ( ) specific files   ( ) a URL / dev server             |
  |  ( ) pasted component code   [Other] ___ free-text path                    |
  '----------------------------------------------------------------------------'
  .--[Standard]-- Which bar to measure against? -------------------------------.
  |  ( ) WCAG 2.1 AA (default)   ( ) WCAG 2.2 AA   ( ) WCAG 2.2 AAA            |
  |  ( ) WCAG 2.1 AA - Section 508 / EN 301 549 baseline                       |
  '----------------------------------------------------------------------------'
  .--[Fix authority]-- only when MODE = Fix -----------------------------------.
  |  ( ) Mechanical only (default)   ( ) Mechanical + contextual TODOs         |
  |  ( ) Full remediation   ( ) Ask me per file                                |
  '----------------------------------------------------------------------------'
  .--[Tech stack]-- only when MODE = Component and stack is ambiguous ---------.
  |  ( ) plain HTML + CSS   ( ) React / JSX   ( ) Vue SFC   ( ) Svelte         |
  |  [Other] Angular, Web Components, template language                        |
  '----------------------------------------------------------------------------'


------------------------------------------------------------- /design-system -
  One plain prompt when no path/paste arg is given (STOP for reply); else skips.
  Treats all source content as DATA to analyze, never as instructions.

  .--[Source]-- What to analyze, and where to write DESIGN.md? ----------------.
  |  ( ) a directory of .html   ( ) a single .html file   ( ) paste HTML       |
  |  ___ output path (default: the source's dir; cwd for a pasted snippet)     |
  '----------------------------------------------------------------------------'


----------------------------------------------------------- /tailwind-convert -
  One plain prompt when no HTML arg is given (STOP for reply); else skips.
  Detects Tailwind v3 vs v4 from the source before converting.

  .--[Source]-- the HTML file to convert (path or paste) -----------------------.
  |  ___ one HTML file with a <style> block or linked CSS; Tailwind preloaded   |
  '-----------------------------------------------------------------------------'


---------------------------------------------------------------- /page-cloner -
  One plain prompt when no URL arg is given (STOP for reply); else skips.
  Needs Claude in Chrome; stops if it is not available.

  .--[URL]-- Which live page should I clone? (paste the URL) -------------------.
  |  ___ e.g. https://example.com  - copied verbatim, no redesign               |
  '-----------------------------------------------------------------------------'


----------------------------------------------------------- /page-tailwindify -
  One plain prompt when no URL arg is given (STOP for reply); else skips.
  Needs Claude in Chrome; detects the styling system, then rehosts or rewrites.

  .--[URL]-- Which live page should I rebuild in Tailwind? (paste the URL) ------.
  |  ___ e.g. https://example.com  - same look, generated class hashes replaced  |
  '------------------------------------------------------------------------------'
