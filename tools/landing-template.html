        How a command runs

        Procedures live in lib/, not skills/. Claude Code never discovers them, so no metadata sits in your context.

        1. 01You

          Type the command

          /unslop ./src

          Anything after the name becomes the tool's argument.

        2. 02Command

          Read the "Load first" banner

          commands/unslop.md

          Frontmatter sets disable-model-invocation: true.

        3. 03Procedure

          Load the procedure

          lib/unslop/SKILL.md

          Read at that moment, and at no other time.

        4. 04On demand

          Pull detail as needed

          references/ scripts/ assets/ examples/

          Rubrics, templates, and runners load only when a step needs them.

        Install

        Run these in any Claude Code session. One plugin, 99 commands and 11 pickers, nothing running in the background.

        2 commands
        Install 
        /plugin marketplace add chrismccoy/forge
/plugin install forge@forge
        Then 
        /forge              # pick a category, then a command
/forge-code         # or one category
/explain-regex      # or any command directly
