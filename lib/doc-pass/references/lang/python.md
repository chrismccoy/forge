## Python rules

Docstrings (a plain string that is the first statement of a module, class or function body) are the doc comments; `#` comments are inline comments.

### Files and tools

- In scope: `.py`, `.pyi`. Out of scope: Django and Jinja templates, migrations with a `Generated by Django` header, generated stubs, `__pycache__`, virtualenvs, `.ipynb` notebooks. Read-only.
- Syntax check: `python -c "import ast, sys; ast.parse(open(sys.argv[1]).read())" <file>` with the project's interpreter, or the checker parse. Never `python -m py_compile`: it writes `__pycache__/` into the project.
- Baselines, run before and after with the project's config: `ruff check`, `ruff format --check` or `black --check`, `flake8`, `pylint`, `mypy` / `pyright` (per error code), `pytest` (never `--snapshot-update`).
- `ruff format` never reflows docstring text; `black` and `docformatter` may change quotes and indentation.
- pydocstyle or ruff `D` rules (`[tool.ruff.lint.pydocstyle] convention`, `select = ["D"]` with an `ignore` list) decide the dialect. Ignored codes (`D212` / `D213`, `D203` / `D211`) set summary and blank-line placement.

### Docstring style

- **Pick the dialect** from existing docstrings and the `convention` setting: Google (`Args:`, `Returns:`, `Raises:`), NumPy (`Parameters` with a dashed underline), Sphinx / reST (`:param x:`, `:raises ValueError:`), or plain. With none, use Google.
- **PEP 257:** triple double quotes; a one-line summary ending in a period; a blank line before any detail; closing quotes on their own line for multi-line docstrings. Imperative mood (`Return the order total.`) when `D401` is enforced, otherwise match the project.
- **Never repeat type hints.** Write `user_id: Primary key of the user.`, not `user_id (int): …`. Name a type only when the signature has none or the dialect requires it (NumPy `x : int` in untyped code). Say what the type cannot: units, ranges, what `None` means.
- **Sections:** `Args` for every parameter except `self` / `cls` (`*args` and `**kwargs` included), `Returns` unless the result is `None`, `Yields` for generators, `Raises` for every exception raised on purpose.
- **Classes:** follow the project's placement. Default: the class docstring describes the class and its role; `__init__` documents its parameters. If the project has no `__init__` docstrings, put parameters in the class docstring, and still give `__init__` a one-line docstring (the coverage scan requires one).
- **Properties:** describe the getter as an attribute (`Total in cents.`), not `Return …`.
- **Attributes:** a string after an assignment is code to the checker. Never add one; use a `#:` comment above the attribute. Existing attribute docstrings stay untouched.
- **Module docstring:** the first statement of the file, before `from __future__` and imports. When the first docstring is a license, it is frozen: put the module description in a `#` comment block directly after it.
- **One-line bodies** (`def f(): ...`, `class Error(Exception): pass`) cannot take a docstring without moving code. Put a `#` comment directly above instead; the coverage scan accepts it.
- **Comments a tool reads.** A docstring sets runtime `__doc__`. `help()`, Sphinx autodoc, Click / Typer help, `argparse` descriptions from `__doc__`, Django admindocs, DRF schemas, FastAPI OpenAPI and graphene / strawberry schemas publish it. Write them for the end reader: no internal notes or file paths.
- **Docstrings that are code.** PLY reads each `t_*` / `p_*` function's docstring as its token regex or grammar rule, and docopt parses the module docstring as the command-line spec. The checker freezes every docstring in a file that imports `ply` (a vendored copy, `from .ply import yacc`, too) or calls `lex.lex(` / `yacc.yacc(` / `TOKEN(`, and the module docstring in one that imports `docopt`: never add, edit or remove them. Document those functions with `#` comments above them, and the file with a `#` block before its first statement; the main session lists the file in `line-docs.txt`, so coverage counts those comments as the docs and the header.

### Coverage

- A module docstring on every file: the first statement is a docstring (a frozen license docstring counts).
- A docstring on every class and every function or method, private (`_helper`) and nested ones included, plus `__init__` and `__call__`.
- Exempt:
  - Other dunders (`__str__`, `__new__`, `__post_init__`).
  - Signatures decorated `@overload` / `@typing.overload` (the implementation still needs one).
  - `@x.setter` and `@x.deleter` (the getter needs one).
  - Any class named `Meta`.
  - In test paths (`tests/`, `test/`, `testing/`, `test_*.py`, `*_test.py`, `conftest.py`), functions, methods and classes named `test_*` / `Test*`, and the unittest / Django hooks `setUp`, `tearDown`, `asyncSetUp`, `asyncTearDown`, `setUpClass`, `tearDownClass`, `setUpTestData`. Fixtures and other helpers there are not exempt.
- A function defined directly in another function's body may use a `#` comment directly above it instead of a docstring.

### Comments that are code

- **Frozen whole** (`#` comments whose text starts with):
  - `#!` (shebang; stays line 1), coding cookies (`# -*- coding: utf-8 -*-`, `# vim: set fileencoding=…`, `# coding=`).
  - `# type:` comments, including `# type: ignore[code]`.
  - `noqa`, `pylint:`, `flake8:`, `mypy:`, `pyright:`, `pyre-*:`, `pytype:`, `ruff:`, `isort:`, `pragma:` (`# pragma: no cover`), `fmt:` (`off`, `on`, `skip`; black and ruff format read it), `yapf:`, `autopep8:`, `pycodestyle:`, `ty:`, `pyrefly:`, `nosec`, `nosemgrep`, `skipcq`, `lgtm`, `codespell:ignore`.
  - Shared: `noinspection`, `NOSONAR`, `language=`, `cspell:`.
- **Frozen whole, comments and docstrings:** any line holding license or credit text (`Copyright`, `(c) 2024`, `SPDX-License-Identifier`, `Licensed under the`, `GNU … General Public License`, `Permission is hereby granted`, `@license`, `@generated`). One such line freezes the whole docstring.
- **Frozen lines:** in docstrings, doctests (`>>>`, its `...` continuations and the expected output up to the next blank line, `# doctest:` flags included); in any docstring or comment, lines starting `.. deprecated::`. Never add a doctest or a `.. deprecated::`. A `>>>` line in a `#` comment is not a doctest and is not checked: leave it as it is.
- **Kept:** `.. versionadded::` and `.. versionchanged::` lines.
- **Trailing directives** (`# type: ignore`, `# noqa: E501`, `# pragma: no cover`, `# fmt: skip`) stay on their line, last. Never append text to them; put the why comment on the line above.
- **Trigger words:** never start a new comment or comment line with a word above (`type:`, `mypy`, `ruff`, `pragma`, `black`, `fmt`, `coding:`, `...`, `>>>`). Reword.

### Django

- **`urls.py`** is the route map: a `#` comment per `path()` / `include()` group with the full path and view.
- **Views:** function views and CBVs name methods, full path, auth (`login_required`, `permission_classes`, mixins), inputs, template and context or response status. DRF viewsets list each action with method and path from the router.
- **Models:** the table, each field's meaning (field options and `Meta` are code), managers and what they filter, `save()` overrides.
- **Signals** are the event map: meaning and payload once at the `Signal()` definition; `@receiver` handlers get one line.
- **Settings:** each `os.environ` / `env()` read is documented once per the env map. Never copy a value.
- **Management commands:** the docstring says what it does and how to run it; `help` strings are code.
- **Celery tasks:** name, arguments, queue, retries and backoff, idempotency, and what enqueues it.

### FastAPI and Flask

- Route decorators: method and full path (router prefix included), dependencies and auth, request model, `response_model` and status codes, `HTTPException` raised. A FastAPI route docstring becomes the OpenAPI description; `summary=` / `description=` arguments are code.
- Pydantic models: the class docstring may feed the schema `description`; `Field( description=… )`, `examples=` and `json_schema_extra` are code. Describe validators in words.
- Dependencies (`Depends`): what they read, yield, clean up and raise.
- Flask: blueprint `url_prefix`, `before_request` hooks, error handlers.

### GraphQL

- In graphene and strawberry, class docstrings and `description=` arguments become the published schema. A new docstring there changes the schema and its snapshot. When a schema file is committed, document those classes with `#` comments only; the facts file then gives the coverage command `--line-docs` for those files, so a `#` block directly above the class counts.
- Resolvers (`resolve_<field>`, `@strawberry.field`): the field, arguments, data loader use, permissions and errors raised.

### Scripts, ML and notebooks-turned-scripts

- CLI entry points (`__main__`, `argparse`, Click, Typer): arguments, exit codes, files read and written. `help=` strings are code.
- Tensors: document shape (`(batch, channels, height, width)`), dtype, device and value range for each tensor parameter and return; say when a function moves devices, casts or mutates in place.
- Device and dtype assumptions (CUDA only, fp16 / bf16) and memory side effects (offload, cache clearing).
- Plugin node classes (ComfyUI `INPUT_TYPES`, `DESCRIPTION`, `tooltip=`) are UI text: code.
- Notebook-derived scripts: run order, inputs, outputs in the module docstring.

### Bug report additions

- `eval`, `exec`, `pickle.load`, `torch.load` without `weights_only=True`, `yaml.load` without `SafeLoader`, `marshal` on untrusted input.
- `subprocess` with `shell=True` or string commands built from input; `os.system`.
- Raw SQL with f-strings or `%` (`cursor.execute`, `.raw()`, `.extra()`, `RawSQL`); `mark_safe` / `|safe` on user data.
- Path traversal (`os.path.join` on user input, unchecked `tarfile` / `zipfile` extraction).
- `requests` without `timeout` or with `verify=False`; SSRF.
- `DEBUG = True`, hard-coded `SECRET_KEY`, `ALLOWED_HOSTS = ["*"]`, `csrf_exempt`, missing `permission_classes`.
- Mutable default arguments, bare `except:` or `except Exception: pass`, naive `datetime.now()`, `assert` as validation.
- Blocking calls in `async def`; N+1 queries without `select_related` / `prefetch_related`.
